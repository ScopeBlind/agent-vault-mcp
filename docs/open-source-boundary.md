# Open-source boundary

This package is intentionally small.

## Open

- MCP tool schemas.
- Signed-page and Context Capsule examples.
- Local Ed25519 signing for compatibility.
- Offline verification.
- Memory proposal flow.
- Hermes/GBrain/agent-runtime docs.

## Not open in this package

- hosted Vault persistence;
- account auth and team controls;
- key custody/recovery;
- managed BRASS/VOPRF issuance;
- DLEQ/nullifier service operation;
- OAuth connectors;
- enterprise audit rooms;
- ScopeBlind Mandate source-pack and LP proof-pack logic.

The open package should create compatibility and trust. The hosted product should provide reliability, custody, managed proof issuance, governance, and vertical workflows.
